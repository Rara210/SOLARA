SOLARIS — Simulation holographique du système solaire

FICHIERS : index.html (structure + HUD), style.css (interface holographique), script.js (scène Three.js, shaders, caméra, bloom).
UTILISATION : une seule scène 3D plein écran. Cliquez une planète (liste ou étiquette) pour y voler, glissez pour orbiter, molette pour zoomer, flèches gauche/droite pour changer de monde, Échap ou « Vue système » pour dézoomer. Le bouton Mode bascule entre hologramme et rendu réaliste.
MISE EN LIGNE : déposez les 4 fichiers à la racine d'un dépôt GitHub, puis Settings > Pages > Deploy from a branch (main, /root).
RÉSEAU : Three.js (jsDelivr) et les polices Google Fonts sont chargés en ligne. Aucune texture externe : tout est généré par le code.
